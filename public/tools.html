SHADDAI MCP Tools

… tools in one connection. Plug SHADDAI into Claude, Cursor or any MCP client and your assistant can use the 7-agent council, the knowledge brain, live markets, and the game-dev library — all through plain conversation.

Connect in 60 seconds

  1. Add SHADDAI to your MCP client. In Claude Desktop, open Settings → Developer → Edit Config and add: 
    {
  "mcpServers": {
    "shaddai": {
      "command": "npx",
      "args": ["-y", "shaddai-mcp"],
      "env": { "SHADDAI_API_URL": "https://shaddai-g81x.onrender.com" }
    }
  }
}
    Cursor and Claude Code use the same block in their MCP settings.
  2. Restart the client. You should see the SHADDAI tools listed.
  3. Just ask. You never call tools by name — describe what you want and the assistant picks the tool. Examples are under each section below.

Optional: set SHADDAI_API_KEY to raise free-tier limits. Money tools stay disabled unless the operator sets SHADDAI_ENABLE_MONEY=1.
