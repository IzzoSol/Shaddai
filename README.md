## ✦ The short version

SHADDAI is a **sovereign AI agent empire** — a council of seven specialized agents, a forge to
build more, a 3D world they live in, and now a living **Temple on Telegram** where the whole thing
actually runs. The premise underneath all of it is simple: the intelligence is *yours*. Bring your

you and the model.

It is not a chatbot with a nice skin. It's an agentic operating layer with a body, a world, and a
will of its own.

## ✦ How it actually works

```
  your free key
       │
       ▼
  ┌─────────────┐   routes to    ┌────────────────────┐
  │  Agent      │───────────────▶│  frontier models    │
  │  Engine     │◀───────────────│  (BYOK: Groq /      │
  └─────────────┘   4-iter loop  │   OpenRouter …)     │
       │                          └────────────────────┘
       │ calls
       ▼
  ┌─────────────┐   ┌──────────┐   ┌───────────┐
  │  200+ real  │   │ episodic │   │  the      │
  │    tools    │   │  memory  │   │  Temple   │
  └─────────────┘   └──────────┘   └───────────┘
```

Each agent runs a short reasoning loop: read the task, decide which skill to call, execute it against
real data, and iterate. Memory persists across sessions, so agents learn your context instead of
starting cold every time.

## ✦ Quickstart

```bash
# 1. install
cd backend && npm install

# 2. configure — never commit this file (it's gitignored)
echo "GROQ_API_KEY=your_free_groq_key" > backend/.env

# 3. launch
npm start                      # serves on http://localhost:3000
```

Open **http://localhost:3000** to land on the front gate, forge your first operative, and walk into
the world — or open the Temple on Telegram and meet the council.

**Deploy:** push to `main` and Render auto-deploys. Set `GROQ_API_KEY`, `ADMIN_TOKEN`, and
`SHADDAI_MERCHANT_WALLET` in the Render dashboard (never in the repo).
