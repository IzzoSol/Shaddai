# Provenance

Reel Forge code and text are original SHADDAI work, written from first principles. No source files, prompts or documentation from other projects were copied. Motion-rendering techniques (deterministic time-driven frames, damped springs, beat grids, synthesized sound, review loops) are general engineering and design practice, and the spring formula is standard damped-oscillator mathematics.

The SHADDAI game-dev library (`backend/knowledge/gamedev/`) currently holds only SHADDAI-original sources: `game-forge`, `motion-studio` (this system) and `shaddai-threejs-gamedev`.
