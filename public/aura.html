⬡ MCP SETUP
AURA is open-source, zero-dependency and published to npm as shaddai-aura (v0.4.0) — it ships as a CLI, a library, and an MCP server (Claude, Claude Code & Cursor · 5 tools) that serves AURA's whole free-answer engine over the Model Context Protocol, so any MCP-capable AI client answers repeats for free before the model spends anything.
⌥ View on GitHub ◈ npm · shaddai-aura
Command
npx -y -p shaddai-aura aura-mcp
Client config — add to your MCP client's mcpServers block
{"mcpServers":{"aura":{"command":"npx","args":["-y","-p","shaddai-aura","aura-mcp"]}}}

Roadmap

AURA improves continuously — here's what's shipping next to save more on every call.

7 movements · live → planned
01
Semantic Caching
Embed prompts with a local model (MiniLM) and match by meaning, so paraphrased & complex prompts hit the cache — not just exact strings.
next
02
Knowledge-Base Seed
Load a real reference corpus so AURA answers substantive questions for free — grows the SEED method beyond zero.
planned
03
Native Prompt Caching
Reuse large system prompts across agent turns via cache_control so they aren't re-billed on every call. Live in aura.optimize({cache:true}) — marks the distilled system prefix cacheable (~90% off after the first call); tools are cached only when not trimmed per turn.
live
04
Cheaper-Model Routing
Send trivial prompts to a local or cheap model; reserve 70B for the hard ones — automatic cost tiering per call.
planned
05
OpenAI-Compatible Proxy
Point any tool (Cursor, Claude Code, your own code) at SHADDAI's endpoint and get token savings automatically — drop-in BYOK.
planned
06
MCP Deepening
Expose savings as an MCP resource and give any MCP client the optimizer directly. Live: aura_select_tools + aura_optimize tools (8 total) and a read-only aura://savings resource — so Claude Code / Cursor can trim their own tools, distill their own system prompt, and compress their own history.
live
07
Self-Learning Loop
AURA already auto-promotes recurring misses to the cache; thresholds keep tuning from live data so every repeated pattern pays off faster over time.
live
