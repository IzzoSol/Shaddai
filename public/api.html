Signals API

A free JSON API for SHADDAI's rug-filtered crypto calls — recent signals, the leaderboard of top runners, live performance, and per-token lookup. Build your own bots, dashboards, and alerts on top of the feed.

1 · Get a free key

Mint a free API key instantly. Free tier: 60 requests/min · 10,000/day. Send it as a Bearer token on every request.

⚠ Save this key now — it is shown only once and cannot be recovered.

2 · Authenticate

curl https://shaddai-g81x.onrender.com/api/v1/stats \
  -H "Authorization: Bearer YOUR_KEY"

3 · Endpoints

GET
/api/v1/calls
Recent calls, newest first. Params: limit≤100, since (ms cursor — poll for live delivery), chain, source.
GET
/api/v1/leaderboard
Top calls ranked by peak multiple. Params: limit≤100, period = all | week | day.
GET
/api/v1/stats
Aggregate scorecard: total calls, 2x+ hit rate, average peak, distribution.
GET
/api/v1/token/:idOrSymbol
Was this token called? Entry, current & peak multiple. e.g. /api/v1/token/JIMOTHY.
POST
/api/v1/keys
Mint a free key. Body: { "label": "..." }. Throttled per IP.
GET
/api/v1/me
Your key's tier, limits, and current usage.

5 · Live delivery (polling)

Save the highest ts you receive, then pass it as since to get only newer calls — no duplicates missed. De-dupe on id.

curl "https://shaddai-g81x.onrender.com/api/v1/calls?since=1784200000000&limit=20" \
  -H "Authorization: Bearer YOUR_KEY"
