VI · MCP & RAG

The council, in your Claude

MCP bridge v…

The seven agents and their mastery knowledge bases — 2,326 indexed passages across 7 knowledge bases, sourced from 166 transcribed documents (~1.2M words) — exposed as a Model Context Protocol server. Plug them into Claude Desktop, Claude Code, or Cursor and get grounded answers pinpointed to the exact retrieved excerpt. No API keys. No localhost. One line.

◈

Seven agents, on call

SHADDAI, NEXUS, ZEROX, ORACLE, TURTLE, QUILL, PIKADON — each with its own mastery knowledge base. run_agent — NEXUS, design a scalable system returns the architect, armed with its store.

◎

Grounded answers, cited

Claude answers from the retrieved passages and cites [Source n] — no invention. rag_ask — using the ORACLE KB, what is manifestation?

⌗

One line. No keys.

No API keys, no external LLM, no localhost server. Wire the whole council into Claude with a single npx command.

Wiring it into Claude
1 · Claude Code:
claude mcp add shaddai -- npx -y shaddai-mcp
2 · Claude Desktop — edit the config (File ▸ Settings ▸ Developer ▸ Edit Config) and paste:
{"mcpServers":{"shaddai":{"command":"npx","args":["-y","shaddai-mcp"]}}}
or Cursor — Settings ▸ Features ▸ MCP ▸ Add new server ▸ stdio, command npx -y shaddai-mcp.
  1. Then ask: "rag_ask — using the ORACLE knowledge base, what is manifestation?"
  2. Or run the full agent: "run_agent — QUILL, write a stoic essay on discipline using your knowledge."
Requires Node ≥ 18 anywhere. The package ships the 7 agents + their knowledge bases; Claude synthesizes grounded answers from the retrieved passages. No API keys, no external LLM, no localhost.
