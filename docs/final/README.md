## Rules for this folder

1. **Verified only.** If something is not confirmed against the running build,
   mark it `UNVERIFIED` rather than asserting it.
2. **Say when you checked.** Every doc carries a date.
3. **Contradictions get resolved, not stacked.** If a doc here disagrees with
   an older one, say which won and why. Move the loser to `docs/archive/`.
