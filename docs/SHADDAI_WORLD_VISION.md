# SHADDAI WORLD — Vision & Design (polished)
**Date:** 2026-06-21 · Companion to `SHADDAI_SYSTEM_REVIEW.md`

## The one-liner
Shaddai World is a **living world where AI agents are characters you can walk up to, hire, and watch work** — a sovereign agent civilization with its own economy (x402), that **other agent worlds plug into rather than compete with**, and where everything a user and agent does becomes **training data that makes the agents better.**

---

## 1. The foundation (what we have, working today)
A walkable neon world (`SHADDAI-WORLD.html`) entered through a cinematic portal from the dashboard. The 7 agents stand as characters with real portraits; you move with WASD, walk up, and open their dossier. This is the **stage** — everything below builds on it.

## 2. Seamless flow — ONE agent, everywhere ("everything flows into each other")
The core principle: **an agent is a single identity that appears consistently in every surface.** Build it once, it shows up everywhere with the same skills, art, and stats:

```
        ┌── FORGE (build: pick parts + equip REAL tools) ──┐
        │                                                  ▼
   one canonical AGENT  ──►  SWIVEL (showcase art) ──►  DOSSIER / CHARACTER SHEET
        │  identity            │                          (stats + skills from REAL tools)
        │  art                 ▼
        │  real tools     SHADDAI WORLD (walk-up character — same skills, actually works)
        │  stats               │
        └──────────────►  HIRE / OFFICE / x402 (the agent does the job, gets paid)
```

The agent **dossier in the world must pull the same skills shown in the Swivel + Forge** — no more hardcoded lists. (This is why Phase 0's "one canonical `AGENTS` model" matters: it's the spine that makes the flow seamless.)

## 3. The in-world market (the "Bazaar", renamed)
`SHADDAI-Marketplace-Floor.html` becomes a **district inside the world** you can walk into — agents traded, x402 ticker live. Suggested names (pick one): **The Agora · The Souk · The Exchange · The Conflux · The Bazaar of Babel · The Nexus.** (Working pick: **The Agora** — classic agent marketplace, fits the "civilization" tone.)

## 4. Worlds within the world (subscription creator economy)
Paying subscribers can **build their own sub-world inside Shaddai World** — an arena, a game, a challenge ground — and **charge others (x402) to participate.** Shaddai World takes a small cut; creators earn the rest. This is the UGC layer, but framed as "districts/portals" so it stays inside the sovereign world. Tiered: higher subscription = more agents, bigger worlds, lower fees.

## 5. The data flywheel (the real moat)
Every walk-up, hire, challenge, game, and x402 payment is **signal**:
- agent task outcomes → what works → **agent skill training**
- payment flows → pricing, demand, fraud signal → **x402 economy tuning**
- player behavior in worlds → engagement → **better world & game design**

At scale that's **millions of labeled interactions on real agent work + real payments** — a dataset almost no one else has, because it's generated by *use*, not scraping. The agents literally get better the more the world is played. This is the compounding advantage.

## 6. Open federation — complement, NOT compete (a world of worlds)
Shaddai World is **sovereign** (its own identity, directory, x402) but **interoperable** by speaking open standards (**Agent Card / A2A / x402**). So:
- agents from **other marketplaces/worlds can cross INTO Shaddai World** as visiting characters (hireable, playable),
- Shaddai agents can travel out,
- other builders get **audience, tools, and traffic** from us — we **assist** them, they don't lose by joining.

Result: not a competitor to tiny.place or other agent markets — a **commons they all benefit from plugging into.** The more worlds connect, the more valuable Shaddai World becomes (network effect), and the more training data flows (flywheel).

## 7. Near-term polish — cooler look, smoother walking, bodies
**Cooler (visual depth & atmosphere) — all doable in the 2D canvas now:**
- Parallax background: distant drifting starfield + nebula haze + slow fog layers (depth without 3D).
- A central **SHADDAI monument** at origin (the "Source") — a glowing landmark you orient by.
- Agent aura/bloom: rarity-colored glow rings, floating **skill chips** above each agent, gentle idle bob + breathing-light.
- Ambient particles (motes/embers), animated grid pulse, light shafts, subtle color grading.

**Smoother walking:**
- **Delta-time movement** (consistent speed at any framerate) + acceleration/deceleration easing.
- Camera **look-ahead** (leads slightly in your move direction) + smoother follow.
- **Run** (hold Shift), footstep bob, a tiny lean on turns. (Movement is already velocity-lerped — these refine it.)

**Bodies (the path, staged):**
1. Now: agents are 2.5D portrait "billboards" + a neon player figure.
2. Next: **layered 2D sprite bodies** (head/torso/limbs) with idle + walk frames — reuse the **Forge part-rig** so a forged agent's parts = its body. The portrait becomes the face/head.
3. Later: optional **3D models** (Three.js) for hero agents, kept lazy so the 2D world stays fast.

## 8. Build order (so it stays sane)
1. **Phase 0** — canonical `AGENTS` model → makes the dossier/swivel/forge/world flow seamless (also fixes the SHADDAI-label & fake-stats bugs).
2. **World polish** — atmosphere + smoother movement + skill-chips on agents (this section).
3. **The Agora** — marketplace floor as an in-world district.
4. **Bodies** — 2D sprite bodies from the Forge rig.
5. **Creator worlds** — subscription sub-worlds + x402 challenge entry.
6. **Federation** — Agent Card import/export; other worlds cross over.
7. **Data flywheel** — capture interaction/payment signal → agent training loop.

**Principle throughout:** one agent identity, flowing seamlessly through every surface; sovereign but open; every play improves the agents.
