# DOC_SPARKS
The law. Matches backend/economy-service.js: closed-loop, one-way, and no cash-out API may ever be added.

SPARKS is Shaddai's in-world point (not Spark Protocol $SPK). Think V-Bucks or WoW gold that cannot leave the game.

## Allowed
- a meter for effort
- a ticket into scarce verbs (install, heat, claim)
- a status number
- a boost lock on a plot

## Forbidden
- redeemable for USD, USDC, HBAR, SOL, stocks or any token
- a stock stream
- a vault or yield product
- anything PayBox or x402 can send OUT

## Sources (print)
Narrow and capped per account per day. Every mint pings the dashboard.
- check-in at home (daily cap)
- finish a class
- teach a class
- seat a skill (small rebate, not a farm)
- get hired (contract start)
- stall sale
- race place 1-3
- work session complete
- culture: class taught, art/track sold, radio spin (tiny, capped), hired to dress a building, exhibit cut when TURTLE hangs the piece

## Sinks (burn or lock)
- rent
- tuition
- Forge install
- pit / race entry
- stall lease
- plot claim
- plot boost lock (1.0-1.5x)
- cosmetics / kits in the Builder Yard
- culture: buy a piece for a home / office / plot slot, hire an agent for a set, unlock a radio slot, submit to the TURTLE wing (jury, scarce), studio rent

Target: sinks >= print over a normal week. If print wins, raise rent/entry. Never add a cash-out.

## Dual layer (later, not in Blender)
- Soft = SPARKS (play, rent, tuition, pits, boost).
- Hard (optional future) = a scarce token or partner rail for governance / cosmetics / claim rights, kept OFF the rent pipe. Gameplay fuel is not an investment object.
- Signage never promises APY, stocks or cash-out.

## Art NFT = a frame, not a cash-out
- Now: art is an inventory item, placeable in a slot, traded for SPARKS in-world.
- Later (optional): an NFT flag meaning "this copy may hang on-chain / in a museum listing". It is provenance + brag. Selling it never converts SPARKS -> USDC.
- Only mint what hung in TURTLE or won a radio week. Radio is a queue, not a streaming-royalty bank.
