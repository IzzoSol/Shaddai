SHADDAI Crypto Data API

One clean, documented front door to live crypto market data — price, trending, new launches, token snapshots and search. No API key. No sign-up. No writes.

Base /api/data/v1 Auth none Format JSON Sources DexScreener · CoinGecko OpenAPI spec ↗

Overview

Every response uses a uniform envelope. Success returns { ok:true, source, cachedAt, data }. When an upstream source is temporarily down the API is honest — it returns { ok:false, error:"source unavailable, retry" } with HTTP 503, never fabricated zeros. Data is lightly cached server-side to respect free-tier rate limits.

This is a thin façade over the market-data proxies SHADDAI already runs. It exists to give developers a clean, versioned, keyless surface — not to add new upstreams.
