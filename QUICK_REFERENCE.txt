QUICK COMMANDS
================================================================================

START SERVER:
  Windows PowerShell:  .\START-SERVER.ps1
  Windows CMD:         START-SERVER.bat
  macOS/Linux:         npm start

CHECK HEALTH:
  curl http://localhost:3000/api/health

LIST AGENTS:
  curl http://localhost:3000/api/agents

EXECUTE TASK:
  curl -X POST http://localhost:3000/api/agents/task \
    -H "Content-Type: application/json" \
    -d '{"agentName":"NEXUS","task":"Build API"}'

VIEW EXECUTIONS:
  curl http://localhost:3000/api/executions?limit=10

TROUBLESHOOTING
================================================================================

Port 3000 in use?
  netstat -ano | findstr :3000
  taskkill /PID <pid> /F

npm install fails?
  npm cache clean --force
  rm -r node_modules package-lock.json
  npm install

Agent offline?
  Check agent running on port 8003-8008
  Restart agent if needed

API returns 500?
  Check server logs
  Restart server: npm start

Memory usage high?
  Check memory: curl http://localhost:3000/api/status
  Restart: pm2 restart shaddai

See docs/TROUBLESHOOTING.md for 30+ more issues.
