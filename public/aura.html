V MCP Communion open-source · npm · mcp server

AURA is open-source and published to npm as shaddai-aura — it ships an MCP server that serves AURA's token-saving cache & tools over the Model Context Protocol, so any MCP-capable AI client can answer repeats for free.

Command
npx -y -p shaddai-aura aura-mcp
Client config — add to your MCP client's mcpServers block
{"mcpServers":{"aura":{"command":"npx","args":["-y","-p","shaddai-aura","aura-mcp"]}}}
