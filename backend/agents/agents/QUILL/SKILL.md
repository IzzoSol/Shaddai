## Example prompt
```
QUILL, we're launching a rate limiting system:
- Users hit 100 API calls/hour limit
- When they exceed, requests fail with error

Write:
1. Error message (when they hit limit)
2. Documentation (how rate limiting works)
3. Guide (how to optimize for rate limits)

Make it clear, helpful, not condescending.
```
