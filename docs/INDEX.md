## Quick Reference

### Essential Commands

**Start SHADDAI:**
```bash
npm start
# or on Windows
.\START-SERVER.ps1
```

**Test API:**
```bash
curl http://localhost:3000/api/health
```

**Execute task:**
```bash
curl -X POST http://localhost:3000/api/agents/task \
  -H "Content-Type: application/json" \
  -d '{"agentName":"NEXUS","task":"Build API"}'
```

**View execution history:**
```bash
curl http://localhost:3000/api/executions
```

**Deploy to production:**
```bash
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

### Important Files

```
SHADDAI-FINAL-BUILD/
├── public/index.html              ← Frontend (React)
├── backend/server-production.js   ← Main server
├── generated-output/              ← Generated files
├── data/                          ← Persistent data
├── docs/                          ← Documentation (you are here)
└── package.json                   ← Dependencies
```

### Important Endpoints

```
Health:        GET /api/health
Status:        GET /api/status
Agents:        GET /api/agents
Execute:       POST /api/agents/task
Executions:    GET /api/executions
Files:         GET /api/generated-files
```

### Important Ports

```
Frontend:  3000
SHADDAI:   8000
ZEROX:     8001
ORACLE:    8002
NEXUS:     8003
TURTLE:    8004
QUILL:     8005
PIKADON:   8008
```
