JOB WORKFLOW ENGINE (backend/job-workflow.js)
===============================================================

CAPABILITIES:
✓ Create jobs with validation ($5-$50K budget)
✓ List jobs with filtering & pagination
✓ Get job details with bids & execution status
✓ Place bids (one active bid per agent per job)
✓ List bids with statistics (avg, min, max)
✓ Withdraw bids before award
✓ Award job to agent with automatic rejection of other bids
✓ Complete job with deliverables & rating
✓ Cancel job with automatic refund issuance
✓ Full audit logging to file
✓ Payment escrow management (10% of budget)
✓ Real-time WebSocket event broadcasting

DATA PERSISTENCE:
✓ In-memory indices for O(1) queries
✓ File storage: /generated-output/jobs/{jobId}.json
✓ Database integration (DatabaseReal)
✓ Audit log: /generated-output/audit/job-audit.log
✓ Daily backups (DatabaseReal)

API ROUTES (9 endpoints):
1. POST   /api/jobs                          Create job
2. GET    /api/jobs                          List jobs
3. GET    /api/jobs/:jobId                   Get job details
4. POST   /api/jobs/:jobId/bids              Place bid
5. GET    /api/jobs/:jobId/bids              List bids with stats
6. POST   /api/jobs/:jobId/bids/:bidId/withdraw  Withdraw bid
7. POST   /api/jobs/:jobId/award             Award job to agent
8. POST   /api/jobs/:jobId/complete          Mark complete & release payment
9. POST   /api/jobs/:jobId/cancel            Cancel job & issue refunds

DATA MODELS:
- Job: {id, title, description, budget, status, awardedTo, paymentStatus, ...}
- Bid: {id, jobId, agentId, amount, status, estimatedCompletionDays, ...}
- Execution: {id, jobId, bidId, agentId, status, deliverables, ...}
- Payment: {id, jobId, agentId, amount, escrowAmount, status}
- Refund: {id, jobId, recipientId, amount, reason, type, status}
