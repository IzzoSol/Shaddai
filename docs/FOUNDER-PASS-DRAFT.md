## 2. Legal gate (resolve BEFORE any sale)
| Piece | Risk |
|---|---|
| Paying money, team builds, holders earn fee share until "2x" | Looks like an investment contract / security (profit from others' efforts, stated return). Needs counsel. |
| Crowdfunding the launch + "supply locks, value rises" talk | Securities / money-raising rules; marketing claims liability |
| Real-money winnings at events | Gambling / skill-game law, varies by state/country |
| Referral commissions on pass sales | Multi-level / pyramid concerns; keep to real product sales, not recruitment |
| Agentic wallet holding tokens | Custody, KYC/AML, money-transmission questions; key security |
| Buybacks/LP/burn tied to price | Market-manipulation optics; disclosure |
| Existing note: Sparks = closed-loop, no yield/vault | Revenue-share would contradict this decision |

## 3. Utility-only version (safer starting point — still get counsel)
- Pass = membership: starter Sparks (spendable in-product, non-redeemable for cash), a forged character, move pack, Signals + Temple access, agent-wallet slot (starts empty / platform credits, not user funds).
- Value comes from USE (access, cosmetics, tickets), not from a promised financial return. No "2x", no fee-share to holders, no "supply lock = price up".
- Plots as in-game land with Sparks upkeep, not revenue-linked fees paid to investors.
- Events: prizes in Sparks/cosmetics first; real-money only after a legal read.
- Referrals: commission on product purchases, capped, no recruitment tiers.
- Treasury funds the roadmap openly; publish what it is for.
