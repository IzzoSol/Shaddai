# DOC_DASHBOARD
The tiles a player sees on login. Design only; no giant screen building.

1. Agent card (skills, frame, energy)
2. Home / plot status (lit, rent, stall sold N)
3. Training queue
4. Race / arena invites
5. SPARKS balance + last 5 transactions
6. Hiring offers
7. Perch / courier jobs

Every mint and every sink makes a ping. A successful first session = one lit window + one SPARKS ping.

Ids: every marker carries a dashboard_id (home.a, stall.001, forge.install, academy.class.01, race.gate, perch.main, plots.deeds ...). Blender == game (markers-v4.json) == dashboard.
